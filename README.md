# MnemoKot 🐈🔐

**MnemoKot** — это современный, бескомпромиссный менеджер паролей для Android, построенный на принципах **100% Offline-first** и многоуровневой криптографической защиты. Приложение не использует интернет, не отправляет данные в облака и полностью исключает риск сетевой компрометации ваших учетных записей.

Проект разработан по канонам **Clean Architecture** с использованием многомодульной структуры, паттерна **MVVM** и самого современного стека Android-разработки.

---

## 🛡️ Архитектура Безопасности

Приложение разделено на изолированные модули ядра (`core`) и интерфейса (`app`), что гарантирует чистоту кода и отсутствие каскадных ошибок:

1. **`:core:crypto` (Криптографический движок AMPG v2)**
   * **Мнемоническая генерация:** Создает взломостойкие пароли на лету из простых запоминающихся фраз пользователя (например, `фиолетовая корова` ➡️ `F1ol3T0v@...`).
   * **Детерминированное усечение корней:** Рассчитывает длину слов фразы так, чтобы сохранить семантику корней, делая пароль визуально узнаваемым для владельца.
   * **ГОСТ 7.79-2000 (Система Б):** Логика транслитерации жестко зашита в виде константных таблиц подстановок для русского, украинского и белорусского алфавитов. Полная защита от изменений системных библиотек.
   * **Leet-speak и Уникальность:** Защита от повторов символов (case-insensitive), мутация знаков и добивка детерминированным хэшем SHA-256 до заданной длины.

2. **`:core:database` (Шифрованное хранилище данных)**
   * **Room + SQLCipher (AES-256):** Полное шифрование файла базы данных на физическом носителе устройства. Без секретного ключа файл представляет собой случайный набор байт.
   * **Защита от "плавающей даты":** База данных хранит только метаданные генерации (соль, дату ротации, длину). Сами мнемонические пароли на диске **не хранятся**, что делает кражу базы бесполезной для злоумышленника.
   * **Асинхронность и Реактивность:** Все операции ввода-вывода используют Kotlin Coroutines (suspend-функции) и Flow, что полностью исключает гонки состояний и зависание интерфейса.

3. **`:core:security` (Модуль аудита и резервного копирования)**
   * **PBKDF2 Авторизация:** Защита профиля по PIN-коду использует хэширование PBKDF2 со случайной солью и 100 000 итераций (никаких небезопасных системных `hashCode()`).
   * **Backup v3 (AES-GCM):** Экспорт и импорт зашифрованных резервных копий. Ключ шифрования бэкапа генерируется через PBKDF2 (200 000 итераций) на основе пароля бэкапа, задаваемого пользователем. Полная независимость от Android Keystore для безопасного переноса на другие устройства.
   * ** passwordAuditor:** Встроенные алгоритмы поверхностного (по метаданным) и глубокого (частотный анализ, перекрестные дубликаты в памяти) аудита базы паролей.

4. **`:app` (Графический интерфейс Jetpack Compose)**
   * **Material 3:** Современный, отзывчивый интерфейс с поддержкой глубокой темной темы для комфортной работы.
   * **Безопасность памяти:** Все критические ViewModels и криптокомпоненты используют массивы `CharArray` и `ByteArray` вместо неизменяемых строк `String`. Ключи и пароли физически затираются из оперативной памяти смартфона методом `.fill()` сразу после использования (защита от Root-дампов памяти).

## 🛠️ Технологический стек

* **Язык разработки:** 100% Kotlin (Idiomatic code)
* **Интерфейс:** Jetpack Compose (Declarative UI)
* **Асинхронность:** Kotlin Coroutines & Flow
* **База данных:** Room Database + SQLCipher-Android (v4.5.4)
* **Внедрение зависимостей:** Dagger Hilt (v2.51.1) с KSP-компилятором
* **Сборочная система:** Gradle 8.6 (Kotlin DSL) + Version Catalog (`libs.versions.toml`)
* **Автоматизация (CI/CD):** GitHub Actions (Автоматическая сборка и проверка при каждом коммите)

## 🚀 Написание кода и запуск

Проект полностью укомплектован локальной оберткой Gradle Wrapper и готов к сборке на любой чистой машине.

### Сборка через GitHub Actions:
Каждый коммит автоматически компилируется на сервере автоматизации. Готовый установочный пакет `.apk` всегда доступен для скачивания во вкладке **Actions** -> **Последний билд** -> раздел **Artifacts** (`mnemokot-debug-apk`).

### Локальный запуск:
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Откройте проект в **Android Studio** (рекомендуется версия Hedgehog / Iguana или новее).
3. Дождитесь окончания синхронизации Gradle.
4. Подключите Android-устройство (минимальная версия **Android 8.0, API 26**).
5. Нажмите кнопку **Run** (зеленый треугольник на верхней панели).
